English ↔ Spanish AI Chatbot

An AI-powered conversational chatbot designed to help users understand and translate between English and Spanish.

Features

- English-to-Spanish and Spanish-to-English assistance
- AI-generated conversational responses using Gemini
- n8n workflow automation for request processing
- Language detection and routing
- Custom web interface built with HTML, CSS, and JavaScript
- Webhook-based communication between the frontend and n8n Cloud

Technologies Used

- HTML
- CSS
- JavaScript
- n8n Cloud
- Google Gemini AI

Project Structure

- "index.html" — Chat interface
- "style.css" — Styling and layout
- "script.js" — Chat interactions and webhook requests
- ".gitignore" — Excludes specified local and configuration files

Configuration

The public repository does not contain the actual n8n webhook URL or API credentials.

1. Import or configure the corresponding n8n workflow in your own n8n environment.
2. Configure the webhook URL in your local copy of the frontend.
3. Ensure the Gemini API credentials are configured securely in n8n.
4. Test the chatbot using your own authorized webhook endpoint.

Important: Never commit API keys, private credentials, or your actual webhook URL to the public repository.
